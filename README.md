# Aftabuddin Mallick: Portfolio

Personal portfolio built with React, Vite and Tailwind CSS. Dark mode, responsive layout, validated contact form and resume download.

## Edit your content
All text, links and projects live in `src/data.js`. Search for `TODO` to find the links you still need to fill in.
Replace `public/Aftabuddin_Mallick_Resume.pdf` to update the resume.

## Run locally
    npm install
    npm run dev

## Deploy
Import the repo into Vercel or Netlify. Build command `npm run build`, output `dist`.
